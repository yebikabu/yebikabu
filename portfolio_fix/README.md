# 个人作品集｜修正版

## 这版修复
- 作品顺序增加独立 `order` 字段，不再依赖 IndexedDB 返回顺序。
- 管理模式下可用 ↑ / ↓ 调整作品顺序并保存。
- 默认进入访客模式：上传、编辑、删除、脚本编辑、个人资料保存均隐藏。
- 首次进入管理模式时设置 4-12 位 PIN，之后输入 PIN 才能显示编辑功能。
- 图片右键菜单被禁用，视频使用 `controlsList="nodownload"` 作为基础防护。
- 图片/视频仍使用 IndexedDB Blob 保存，不塞进 localStorage。

## 重要安全说明
这是“本机作品集”的访问控制，只能防止普通访客误编辑，**不能当作真正的互联网安全系统**。如果把这个纯 HTML 网站公开部署，浏览器里的图片/视频本身就已经发送给访客，技术上无法彻底阻止截图、录屏、开发者工具或直接保存媒体。

如果要真正上线给 HR/客户访问，同时防止陌生人修改你的作品，需要后端账号认证 + 数据库权限（RLS）+ 私有对象存储/签名 URL。不要把管理员密码写死在前端。

## 使用
双击 `index.html`。首次点击右上角“进入管理模式”设置 PIN。
